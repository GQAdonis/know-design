# KnowDesign brand resources

Icons for the KnowDesign build, selected by the brand descriptor (`packages/release/src/brand.ts`);
Open Design builds keep using `tools/pack/resources/{mac,win,linux}`.

Source: the KnowMe "K" mark (`know-me-system/desktop/branding/app-icon-source.svg`, tauri icons
`desktop/src-tauri/icons/icon.{icns,ico,png}`), per decision D-005. `mac/icon.png` is rendered from that SVG at
1024 px; `.icns` and `.ico` are the KnowMe-generated files; `linux/icon.png` is the same 1024 px render.
