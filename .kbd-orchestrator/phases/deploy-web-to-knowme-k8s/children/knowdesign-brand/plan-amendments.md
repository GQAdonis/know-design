# Plan amendments — knowdesign-brand (2026-10-06)

Authoritative; also merged into `plan.md` below the change list. Operator instruction: "rename everything … remove the possibility of clashing with the old … include renaming the repository itself."

- **Change 19** — the brand descriptor is the single source for every OS-observable identifier: product name + channel variants, appId (all platforms), product slug, URL scheme, data/user-state directory names, sidecar IPC product slug, default namespace/port, MCP server name, CLI bin name, release origin, GitHub slug, image repo. `tools-pack`, desktop, packaged, daemon and web import it; the Windows/Linux hard-coded appIds and the per-platform `PRODUCT_NAME` copies are removed. **Also: bake `OD_BUILD_PROFILE=knowdesign` into the packaged config** so a Finder launch is knowdesign by construction (closes commerce-removal Delta 1); acceptance adds a packaged test that launches **without** the environment variable and asserts the profile is on.
- **Change 20** — "register a KnowDesign scheme **alongside** the existing one" is **replaced**: a knowdesign build registers only `knowdesign://` (mac Info.plist, NSIS, runtime, Linux MimeType, validators) and never `opendesign://`/`od://` OS handlers, so it cannot steal or lose invite/activation links to a still-installed original. Identity also covers: bundle/exe/installer/AppImage names, install paths, shortcuts, uninstall + App Paths registry keys, userData/launcher/installation roots, sidecar socket/pipe prefixes and `--od-stamp` flag product component, daemon default port, `~/.knowdesign` user-state dir and the project manifest dir, MCP server name, and the CLI bin.
- **Change 21** — adds the GitHub slug literals (~25 runtime places incl. UI links), compose/helm/docker image names, Helm chart name, workflow display strings, and **renaming the repository `GQAdonis/open-design` → `GQAdonis/knowdesign`** (operator-confirmed name; local checkout directory deliberately kept). The rename is the last irreversible step: re-confirm immediately before running it; afterwards update `origin`, verify redirects, Actions and registry, and leave `upstream` (nexu-io) untouched.
- **Change 22** — unchanged, plus the rehearsal also measures the added identity literals' merge cost.
- **Acceptance (phase)**: with the original Open Design installed and running, a KnowDesign build installs and runs beside it with no shared bundle ID, URL handler, data directory, socket, port, MCP entry, user-state directory or CLI name; `brand/verify` finds no old-brand string outside the must-not-rename list.
