KnowDesign Review · flows

From a design in KnowDesign to a customer link, desktop or cloud

Each flow below shows what you do, what the review hub or the Universal Agent Runtime does in response, and a link into that screen of the prototype. Hub endpoints are the proposed contract for review.know-me.tools. UAR requests follow docs/AGUI_V1.md.

Architecture

Same agent experience, two ways to run it

The desktop app starts a CLI agent on your machine. In the cloud there's no CLI, so the hub asks UAR to run the agent. Both send the same AG-UI events to the same blocks on screen.

Desktop

KnowDesign appweb UI
→
Local daemonapps/daemon
→
CLI agentClaude Code · Codex

Files land on your disk. Publishing uploads a snapshot to the hub.

Cloud (Studio)

Browserdesign.know-me.tools
→
Review hubreview.know-me.tools
→
UAR/api/uar/ag-ui/agents/{id}
→
Models + MCP toolsCedar-gated

Files land in the cloud workspace. Identity comes from Kratos; flint-gate issues the token UAR checks.

What stays the same
  • Reasoning, tool steps, file writes and text show up as the same blocks.
  • Risky tools pause and wait for you. In UAR that pause is an interrupt; your answer is a resume.
  • Publish, comments, approval and release all run through the same review hub.
